# @brrritscold/testing-core-js

Runtime-agnostic test helpers.

Anything that depends on node built-ins or node-only packages belongs in [`@brrritscold/testing-core-node`](../testing-core-node) instead.

## Installation

```bash
pnpm add @brrritscold/testing-core-js
```

API docs: `pnpm --filter @brrritscold/testing-core-js generate:docs` (typedoc → `docs/`).
