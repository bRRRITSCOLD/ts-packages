# @brrritscold/testing-core-js

Runtime-agnostic test helpers.

Anything that depends on node built-ins or node-only packages belongs in [`@brrritscold/testing-core-node`](https://www.npmjs.com/package/@brrritscold/testing-core-node) instead.

## Installation

```bash
pnpm add @brrritscold/testing-core-js
```
