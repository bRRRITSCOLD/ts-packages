# @brrritscold/testing-core-node

Node-only test helpers — testcontainers wrappers (`docker`) and HTTP interceptors (`nock`).

## Installation

```bash
pnpm add @brrritscold/testing-core-node
```

API docs: `pnpm --filter @brrritscold/testing-core-node generate:docs` (typedoc → `docs/`).
