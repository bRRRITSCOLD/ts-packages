# @brrritscold/core-js

Runtime-agnostic (browser + node) core utilities — `date`, `error`, `obj`, `query`, `zod`.

## Installation

```bash
pnpm add @brrritscold/core-js
```

API reference: [brrritscold.github.io/ts-packages](https://brrritscold.github.io/ts-packages/modules/_brrritscold_core-js.html) · [source](https://github.com/bRRRITSCOLD/ts-packages/tree/main/packages/core-js) · [changelog](https://github.com/bRRRITSCOLD/ts-packages/blob/main/packages/core-js/CHANGELOG.md)


## Features

- ESM + CJS compatabilities
  - any `import ... from '@brrritscold/core-node'` in documentation can be replaced with a `const ... = require('@brrritscold/core-node')`
