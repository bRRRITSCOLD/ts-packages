# @brrritscold/core-js

Runtime-agnostic (browser + node) core utilities — `date`, `error`, `obj`, `query`, `zod`.

## Installation

```bash
pnpm add @brrritscold/core-js
```

API docs: `pnpm --filter @brrritscold/core-js generate:docs` (typedoc → `docs/`).


## Features

- ESM + CJS compatabilities
  - any `import ... from '@brrritscold/core-node'` in documentation can be replaced with a `const ... = require('@brrritscold/core-node')`
